# Security Policy

## Supported versions

Only the latest commit on `main` is supported. There are no long-term support branches.

## Reporting a vulnerability

Please report security issues privately via GitHub's "Report a vulnerability" feature on the Security tab, or by email to the maintainer. Do not open a public issue for a security problem.

## Scope

This template ships only Python standard-library scripts and markdown. There are no network calls, no dependencies, and no runtime services. The main risks are path traversal or unsafe file writes in the helper scripts; please report those.

## Response

You can expect an acknowledgement within 7 days and a fix or mitigation plan within 30 days for confirmed issues.
